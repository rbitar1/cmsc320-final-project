# CMSC 320 Final Project

## Introduction

This repository contains our final project for **CMSC 320: Introduction to Data Science** at the University of Maryland.

Our project explores the relationship between musical characteristics and song popularity using Spotify track data. We will walk through the complete data science pipeline, including data acquisition, data cleaning, database organization, exploratory data analysis, hypothesis testing, machine learning, and visualization.

## Dataset

We are using the **Spotify Tracks Dataset**, which contains approximately 114,000 tracks across 114 genres. The dataset includes information about each track, including its artist, genre, popularity, and audio features such as danceability, energy, loudness, acousticness, instrumentalness, liveness, valence, and tempo.

**Source:** [Spotify Tracks Dataset on Hugging Face](https://huggingface.co/datasets/sfiore/spotify-tracks-dataset)

## Project Goals

All members of our group are frequent Spotify users who listen to music regularly, and we are interested in understanding how data about songs can be used to identify music that listeners may enjoy.

Our project will investigate the relationships between musical characteristics, genre, and song popularity. We will use exploratory data analysis and hypothesis testing to identify meaningful patterns in the data and use machine learning to explore whether a song's popularity can be predicted from its available characteristics.
